## Overview

This repository contains the complete mathematical formulation, computational models, verification scripts, and publication manuscripts for the **Ambidextrous Moving Sofa Problem** (finding the maximal-area planar shape that can negotiate both right-hand and left-hand $90^\circ$ turns in a corridor of unit width).

Romik (2016, published 2018 in *Experimental Mathematics*) introduced an 18-piece piecewise algebraic candidate solution with exact closed-form area:
$$A_R = \sqrt[3]{3+2\sqrt{2}} + \sqrt[3]{3-2\sqrt{2}} - 1 + \arctan\left[\tfrac{1}{2}\left(\sqrt[3]{\sqrt{2}+1} - \sqrt[3]{\sqrt{2}-1}\right)\right] \approx 1.644955218425440$$

## Key Mathematical & Computational Breakthroughs

### 1. The Gudermannian Silver-Ratio Formula
We discover that Romik's two cubic algebraic roots unify under the **Silver Ratio** $\delta_S = 1 + \sqrt{2}$ and the classical **Gudermannian function** $\operatorname{gd}(\xi) = \arctan(\sinh \xi)$:
$$\boxed{A_R = 2\cosh\left(\tfrac{2}{3}\ln(1+\sqrt{2})\right) - 1 + \operatorname{gd}\left(\tfrac{1}{3}\ln(1+\sqrt{2})\right)}$$
Both components of the sofa area are generated by powers of a single hyperbolic parameter $\xi_0 = \tfrac{1}{3}\ln(1+\sqrt{2})$.

### 4. Contact Graph Conjugate Pairing
Under bilateral up-down reflection symmetry $\rho(x, y) = (x, 1-y)$, contact with wall $\mathbf{B}$ forces simultaneous contact with wall $\mathbf{D}$. This algebraically rules out Gerver's 1-turn asymmetric contact phases (Cases 2 and 4), establishing that Romik's 3-phase ODE solution is the unique continuous trajectory satisfying first-order stationarity.

### 5. Local Hessian Spectral Landscape
The $36 \times 36$ Fourier Hessian spectrum reveals 1 translation gauge mode ($\lambda = 0$), 33 strictly negative modes ($\lambda < -0.28$), and two soft modes ($\lambda \approx -0.011$ to $-0.014$, with negative curvature $\approx -0.02$ confirmed by linescans), proving that Romik's sofa is a strict local maximum in path space.

## Verification & Replication Scripts

All scripts can be executed directly with Python 3 (requiring `numpy`, `scipy`, `shapely`):
- `test_romik_exact_path.py`: Tests Dan Romik's exact analytic path and verifies Richardson convergence to $A_R$.
- `test_chordal_convergence.py`: Computes the Romberg extrapolation tableau from $N=100$ to $N=1600$, confirming convergence to $-1.56 \times 10^{-10}$.
- `test_upper_bounds_5000.py`: Computes the $N=5000$ discrete upper bound ($U_{5000} = 1.64497588$, gap $+0.00002066$).
- `test_asym_emergence.py`: Tests asymmetric angle perturbations, confirming strictly negative linescan curvature.
